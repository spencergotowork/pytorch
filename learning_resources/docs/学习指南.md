# PyTorch 源码学习指南

## 学习目标

作为熟悉PyTorch Python API、使用过Accelerate/DeepSpeed的开发者，你将通过本指南深入理解PyTorch的内部实现。

## 学习路线图

```
第1-2周: 快速入门
  ↓
第3-5周: 核心机制
  ↓
第6-8周: 实践项目
  ↓
第9-12周: 专项深入
  ↓
第13周+: 贡献代码
```

## 阶段划分

### 阶段1: 快速入门 (Week 1-2, 约20小时)

**学习文档**: `阶段1-快速入门.md`

**目标**: 理解PyTorch的整体架构和基本执行流程

**必修内容**:
- [ ] PyTorch的4层架构
- [ ] DispatchKey和调度系统
- [ ] 追踪torch.add()的完整调用链
- [ ] 理解grad_fn和计算图

**实践任务**:
- [ ] 运行 `demo/trace_simple.py`
- [ ] 运行 `demo/visualize_autograd.py`
- [ ] 使用 `tools/explore_pytorch.sh` 查找3个算子

**完成标准**:
- 能画出4层架构图
- 能解释DispatchKey的作用
- 能追踪一个算子从Python到C++的调用链

### 阶段2: 核心机制 (Week 3-5, 约30小时)

**学习文档**: `阶段2-核心机制.md`

**目标**: 深入理解Dispatcher和Autograd两大核心系统

**必修内容**:
- [ ] Dispatcher的工作原理
- [ ] OperatorEntry和内核注册
- [ ] Autograd引擎的执行流程
- [ ] 计算图的构建和反向传播

**实践任务**:
- [ ] 阅读 `c10/core/DispatchKey.h`
- [ ] 阅读 `torch/csrc/autograd/engine.cpp`
- [ ] 实现3个自定义autograd函数

**完成标准**:
- 能解释Dispatcher如何选择内核
- 能解释反向传播的拓扑排序过程
- 能实现复杂的自定义autograd函数

### 阶段3: 实践项目 (Week 6-8, 约30小时)

**学习文档**: `阶段3-实践项目.md`

**目标**: 通过修改代码验证理解

**必修内容**:
- [ ] 如何修改并编译PyTorch
- [ ] 如何添加自定义算子
- [ ] 如何为算子添加autograd支持

**实践任务**:
- [ ] 在C++层添加日志并重新编译
- [ ] 实现一个完整的自定义算子
- [ ] 为自定义算子实现前向和反向

**完成标准**:
- 成功编译修改后的PyTorch
- 实现的算子能正确计算梯度
- 理解算子注册的完整流程

### 阶段4: 专项深入 (Week 9-12, 约40小时)

**学习文档**: `阶段4-专项深入.md`

**目标**: 选择一个方向深入研究

**方向选择** (选其一):
- [ ] 分布式训练 (DDP/FSDP/NCCL)
- [ ] 编译器 (TorchScript/Inductor/Dynamo)
- [ ] CUDA开发 (自定义CUDA kernel)

**完成标准**:
- 能阅读并理解该领域的核心代码
- 能解决该领域的实际问题
- 写一篇技术总结文档

### 阶段5: 贡献代码 (Week 13+, 持续)

**学习文档**: `阶段5-贡献代码.md`

**目标**: 为PyTorch主仓库贡献代码

**任务**:
- [ ] 修复一个"good first issue"
- [ ] 提交PR并通过code review
- [ ] PR被合并到主仓库

## 时间投入建议

**每周时间分配** (每周10-15小时):
- 40% 阅读源码
- 30% 动手实践
- 20% 调试和实验
- 10% 记录笔记

**学习节奏**:
- 每天投入: 2-3小时 (推荐)
- 周末集中: 不推荐 (容易忘记)

## 学习方法

### 有效方法
✅ **深度优先**: 选一个话题,追踪到底
✅ **动手验证**: 每学一个概念就写代码验证
✅ **画图理解**: 用图表整理调用关系
✅ **做好笔记**: 记录理解和困惑

### 避免陷阱
❌ 试图一次理解所有代码
❌ 只看不做
❌ 跳过基础直接看高级特性
❌ 遇到困难就放弃
