# 阶段2: 核心机制

## 1. Dispatcher 深入

### 1.1 Dispatcher 单例模式

**核心类**: `aten/src/ATen/core/dispatch/Dispatcher.h`

```cpp
class Dispatcher {
public:
  static Dispatcher& singleton();

  // 注册算子
  RegistrationHandleRAII registerDef(FunctionSchema schema);
  RegistrationHandleRAII registerImpl(OperatorName name, DispatchKey key, KernelFunction func);

  // 调用算子
  template<typename Return, typename... Args>
  Return call(const TypedOperatorHandle<Return(Args...)>& op, Args... args);
};
```

**关键概念**:
- **单例**: 全局唯一的Dispatcher实例
- **OperatorTable**: 存储所有已注册算子
- **DispatchTable**: 每个算子的(DispatchKey → Kernel)映射

### 1.2 OperatorEntry 结构

**文件**: `aten/src/ATen/core/dispatch/OperatorEntry.h`

```cpp
class OperatorEntry {
private:
  OperatorName name_;                    // 算子名称
  FunctionSchema schema_;                // 函数签名
  DispatchTable dispatchTable_;          // Dispatch键到内核的映射
  KernelFunction fallbackKernel_;        // 回退内核
};
```

**DispatchTable 查找流程**:
```
1. 从输入张量计算DispatchKeySet
2. 按优先级遍历DispatchKeySet
3. 在dispatchTable_中查找第一个匹配的内核
4. 如果没找到,使用fallbackKernel_
```

### 1.3 DispatchKey 优先级

**优先级顺序** (从高到低):

```
Autograd层:
  AutogradCPU, AutogradCUDA, ... (最高优先级)
    ↓
功能层:
  Sparse, Quantized, ...
    ↓
后端层:
  CPU, CUDA, HIP, XPU, ...
    ↓
Fallback:
  CatchAll (最低优先级)
```

**示例**:
```python
x = torch.randn(3, requires_grad=True, device='cuda')
# DispatchKeySet: {AutogradCUDA, CUDA, Dense}
# 调用add时,优先级: AutogradCUDA > CUDA > Dense
```

### 1.4 算子注册机制

**方式1: native_functions.yaml (推荐)**

```yaml
- func: my_op(Tensor self, Scalar alpha) -> Tensor
  dispatch:
    CPU: my_op_cpu
    CUDA: my_op_cuda
```

自动生成注册代码

**方式2: 手动注册**

```cpp

  // 实现
}

// 注册

  m.def("my_op", my_op_cpu);
}

}
```

## 2. Autograd 引擎详解

### 2.1 核心类

**Engine** (`torch/csrc/autograd/engine.h`):

```cpp
class Engine {
public:
  static Engine& get_default_engine();

  variable_list execute(
    const edge_list& roots,
    const variable_list& inputs,
    bool keep_graph,
    bool create_graph
  );

private:
  // 每个设备有独立的ReadyQueue
  std::vector<std::shared_ptr<ReadyQueue>> device_ready_queues_;
};
```

**关键概念**:

- **GraphTask**: 表示一次完整的反向传播任务
- **ReadyQueue**: 每个设备(CPU/各GPU)有独立的就绪队列
- **thread_main**: 工作线程从队列取任务并执行

反向传播是**多线程**的，不同设备的任务会分发到对应的ReadyQueue。

### 2.2 Node 基类

**文件**: `torch/csrc/autograd/function.h`

```cpp
struct Node {
  // 核心方法:计算梯度
  virtual variable_list apply(variable_list&& inputs) = 0;

  // 前驱节点(计算图中的依赖)
  std::vector<Edge> next_functions_;

  // 元数据
  uint64_t sequence_nr_;  // 序列号,用于拓扑排序
  bool is_executable_;
};
```

**常见Node类型**:
- `AddBackward0` - add操作的反向
- `MulBackward0` - mul操作的反向
- `AccumulateGrad` - 叶子节点的梯度累积

### 2.3 Edge 结构

**文件**: `torch/csrc/autograd/edge.h`

```cpp
struct Edge {
  std::shared_ptr<Node> function;  // 指向的Node
  uint32_t input_nr;               // 输入索引
};
```

**用途**: 连接计算图中的Node

### 2.4 反向传播执行流程

**步骤详解**:

```cpp
// 1. 初始化
Engine::execute(roots, ...) {
  // roots是需要求导的变量(通常是loss)

  // 2. 计算依赖关系
  compute_dependencies(roots);
  // 为每个Node计算有多少后继节点依赖它

  // 3. 初始化ready_queue
  for (auto& root : roots) {
    ready_queue_.push({root.grad_fn, {root.grad}});
  }

  // 4. 拓扑排序执行
  while (!ready_queue_.empty()) {
    auto task = ready_queue_.pop();

    // 调用Node::apply计算梯度
    auto grad_inputs = task.fn->apply(task.inputs);

    // 将梯度传递给前驱节点
    for (size_t i = 0; i < grad_inputs.size(); ++i) {
      Edge& edge = task.fn->next_functions_[i];

      // 减少依赖计数
      if (--dependencies_[edge.function] == 0) {
        // 所有依赖都已计算完,加入队列
        ready_queue_.push({edge.function, ...});
      }
    }
  }
}
```

### 2.5 具体例子: AddBackward

**生成代码位置**: `torch/csrc/autograd/generated/Functions.h` (编译后生成)

```cpp
struct AddBackward0 : public Node {
  variable_list apply(variable_list&& grads) override {
    // 输入: grad_output (来自后继节点)
    // 输出: grad_input_self, grad_input_other

    auto grad_output = grads[0];

    // add操作的梯度:
    // d(self + alpha*other)/d(self) = 1
    // d(self + alpha*other)/d(other) = alpha

    variable_list result(2);
    result[0] = grad_output;              // grad_self
    result[1] = grad_output * alpha_;     // grad_other

    return result;
  }

  Scalar alpha_;  // 保存的参数
};
```

## 3. 算子实现模式

### 3.1 CPU 算子实现

**文件**: `aten/src/ATen/native/BinaryOps.cpp`

```cpp
Tensor add_cpu(const Tensor& self, const Tensor& other, const Scalar& alpha) {
  // 1. 参数检查
  TORCH_CHECK(self.device() == other.device());

  // 2. 创建输出张量
  Tensor result = at::empty_like(self);

  // 3. 使用TensorIterator处理维度和类型
  auto iter = TensorIteratorConfig()
    .add_output(result)
    .add_input(self)
    .add_input(other)
    .build();

  // 4. 调用kernel
  add_kernel(iter, alpha);

  return result;
}
```

**TensorIterator 的作用**:
- 处理broadcast
- 处理不同数据类型
- 向量化优化

### 3.2 CUDA 算子实现

**文件**: `aten/src/ATen/native/cuda/BinaryKernel.cu`

```cpp
template<typename scalar_t>
__global__ void add_kernel(
    scalar_t* out,
    const scalar_t* a,
    const scalar_t* b,
    scalar_t alpha,
    int64_t n) {
  int idx = blockIdx.x * blockDim.x + threadIdx.x;
  if (idx < n) {
    out[idx] = a[idx] + alpha * b[idx];
  }
}

Tensor add_cuda(const Tensor& self, const Tensor& other, const Scalar& alpha) {
  Tensor result = at::empty_like(self);

  int64_t n = self.numel();
  int threads = 256;
  int blocks = (n + threads - 1) / threads;

  AT_DISPATCH_FLOATING_TYPES(self.scalar_type(), "add_cuda", [&] {
    add_kernel<scalar_t><<<blocks, threads>>>(
      result.data_ptr<scalar_t>(),
      self.data_ptr<scalar_t>(),
      other.data_ptr<scalar_t>(),
      alpha.to<scalar_t>(),
      n
    );
  });

  return result;
}
```

### 3.3 向量化优化 (CPU)

**文件**: `aten/src/ATen/native/cpu/BinaryOpsKernel.cpp`

```cpp
void add_kernel(TensorIteratorBase& iter, const Scalar& alpha_scalar) {
  AT_DISPATCH_ALL_TYPES(iter.dtype(), "add_cpu", [&] {
    auto alpha = alpha_scalar.to<scalar_t>();

    // 向量化loop
    cpu_kernel_vec(iter,
      [=](scalar_t a, scalar_t b) -> scalar_t {
        return a + alpha * b;  // 标量版本
      },
      [=](Vectorized<scalar_t> a, Vectorized<scalar_t> b) {
        return a + Vectorized<scalar_t>(alpha) * b;  // 向量版本
      }
    );
  });
}
```

## 4. 自定义 Autograd Function

### 4.1 Python层实现

```python
class MyFunction(torch.autograd.Function):
    @staticmethod
    def forward(ctx, input, weight, bias):
        # 1. 保存用于backward的张量
        ctx.save_for_backward(input, weight, bias)

        # 2. 计算前向结果
        output = input.mm(weight.t())
        if bias is not None:
            output += bias.unsqueeze(0).expand_as(output)

        return output

    @staticmethod
    def backward(ctx, grad_output):
        # 1. 取出保存的张量
        input, weight, bias = ctx.saved_tensors

        # 2. 计算各参数的梯度
        grad_input = grad_weight = grad_bias = None

        if ctx.needs_input_grad[0]:
            grad_input = grad_output.mm(weight)
        if ctx.needs_input_grad[1]:
            grad_weight = grad_output.t().mm(input)
        if bias is not None and ctx.needs_input_grad[2]:
            grad_bias = grad_output.sum(0)

        return grad_input, grad_weight, grad_bias
```

### 4.2 C++层实现

**文件**: 自定义文件

```cpp
#include <torch/extension.h>

// 前向函数
torch::Tensor my_function_forward(
    torch::Tensor input,
    torch::Tensor weight,
    torch::Tensor bias) {
  auto output = input.mm(weight.t());
  if (bias.defined()) {
    output += bias.unsqueeze(0).expand_as(output);
  }
  return output;
}

// 反向函数
std::vector<torch::Tensor> my_function_backward(
    torch::Tensor grad_output,
    torch::Tensor input,
    torch::Tensor weight) {
  auto grad_input = grad_output.mm(weight);
  auto grad_weight = grad_output.t().mm(input);
  auto grad_bias = grad_output.sum(0);

  return {grad_input, grad_weight, grad_bias};
}

// Python绑定
PYBIND11_MODULE(TORCH_EXTENSION_NAME, m) {
  m.def("forward", &my_function_forward, "forward");
  m.def("backward", &my_function_backward, "backward");
}
```

### 6.2 理解性能瓶颈

**常见瓶颈**:
1. **Dispatcher开销**: 小算子调用频繁
2. **Kernel启动**: CUDA kernel启动延迟
3. **内存拷贝**: CPU↔GPU数据传输
4. **同步点**: `.item()`, `.cpu()` 等

**优化方向**:
1. 算子融合 (减少Dispatch次数)
2. 使用JIT编译
3. 异步执行
4. 避免不必要的同步
