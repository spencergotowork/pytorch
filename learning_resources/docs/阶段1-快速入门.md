# 阶段1: 快速入门

## 1. PyTorch 架构

### 1.1 四层架构

```
┌─────────────────────────────────┐
│  torch/       Python前端        │
│  - nn.Module, optim, autograd  │
└─────────────────────────────────┘
              ↓
┌─────────────────────────────────┐
│  torch/csrc/  Python/C++绑定    │
│  - autograd引擎, JIT编译器      │
└─────────────────────────────────┘
              ↓
┌─────────────────────────────────┐
│  aten/       张量运算库         │
│  - Dispatcher, 算子实现         │
└─────────────────────────────────┘
              ↓
┌─────────────────────────────────┐
│  c10/        核心库             │
│  - DispatchKey, Device, 类型    │
└─────────────────────────────────┘
```

**各层职责**:

- **c10/** (C++ 10): 核心类型系统
  - `DispatchKey`: 调度键枚举
  - `TensorOptions`: 张量配置
  - `Device`, `DeviceType`: 设备抽象

- **aten/** (A Tensor Library): 张量运算
  - `Dispatcher`: 中央调度器
  - `native/`: 算子实现(CPU/CUDA等)
  - 算子注册和查找机制

- **torch/csrc/**: C++实现
  - `autograd/`: 自动微分引擎
  - `jit/`: TorchScript编译器
  - Python绑定代码

- **torch/**: Python前端
  - 用户API (nn, optim等)
  - 编译器 (_dynamo, _inductor)

## 2. DispatchKey 和调度系统

### 2.1 DispatchKey 概念

**DispatchKey** 是一个枚举类型，标识张量的"身份":

```cpp
// c10/core/DispatchKey.h
enum class DispatchKey : uint16_t {
  // 后端
  CPU,
  CUDA,
  HIP,
  XPU,

  // 功能
  Dense,
  Sparse,
  Quantized,
  Autograd,

  // ...
};
```

**DispatchKeySet** 是多个DispatchKey的组合:

```cpp
// 一个CUDA张量在autograd模式下的DispatchKeySet可能包含:
// {CUDA, Dense, AutogradCUDA}
```

### 2.2 Dispatcher 工作流程

```
torch.add(x, y)
    ↓
Dispatcher::singleton()
    ↓
从x,y获取DispatchKeySet
    ↓
在OperatorTable中查找 "aten::add"
    ↓
根据DispatchKeySet选择内核
    ↓
调用对应的C++函数
```

**关键代码位置**:
- 定义: `c10/core/DispatchKey.h`
- 实现: `aten/src/ATen/core/dispatch/Dispatcher.cpp`

### 2.3 为什么用Dispatch而不是虚函数?

1. **性能**: 直接表查找比虚函数调用快
2. **灵活性**: 可以动态添加后端
3. **组合性**: 可以组合多个功能(如Autograd + CUDA)

## 3. 追踪 torch.add() 调用链

**详细说明**: 见 `调用链详解-torch.add.md`

### 3.1 简化的调用流程

```
torch.add(x, y)                       Python调用
    ↓
at::add()                             inline函数
[build/aten/src/ATen/ops/add.h:27]
    ↓
at::_ops::add_Tensor::call()          调用结构体方法
    ↓
add_Tensor::call()                    实际实现
[build/aten/src/ATen/Operators_2.cpp]
  → op.call() (TypedOperatorHandle)
    ↓
Dispatcher::singleton()               运行时调度
根据DispatchKeySet选择内核:
- AutogradCPU/CUDA (如有requires_grad)
- CPU/CUDA (后端)
    ↓
TORCH_META_FUNC2(add, Tensor)         元函数
[aten/src/ATen/native/BinaryOps.cpp:151]
    ↓
add_kernel()                          实际计算
[CPU] aten/src/ATen/native/cpu/BinaryOpsKernel.cpp
[CUDA] aten/src/ATen/native/cuda/BinaryOpsKernel.cu
```

## 4. Autograd 基础

### 4.1 核心概念

**grad_fn**: 记录创建张量的操作
```python
x = torch.tensor([1.0], requires_grad=True)
y = x + 2  # y.grad_fn = <AddBackward0>
z = y * 3  # z.grad_fn = <MulBackward0>
```

**计算图**: 通过grad_fn连接的DAG
```
x (叶子节点)
 ↓
AddBackward0 → y
 ↓
MulBackward0 → z
```

**反向传播**: 从loss反向遍历图,计算梯度
```python
z.backward()  # 自动计算 x.grad
```

### 4.2 关键数据结构

**Variable** (`torch/csrc/autograd/variable.h`):
```cpp
struct Variable {
  Tensor data;              // 数据
  bool requires_grad;       // 是否需要梯度
  shared_ptr<Node> grad_fn; // 创建该变量的函数
  Tensor grad;              // 累积的梯度
};
```

**Node** (`torch/csrc/autograd/function.h`):
```cpp
struct Node {
  virtual variable_list apply(variable_list&& inputs) = 0;
  vector<Edge> next_functions;  // 指向前驱节点
};
```

### 4.3 反向传播流程

```
loss.backward()
    ↓
Engine::execute()
    ↓
拓扑排序所有Node
    ↓
对每个Node调用apply():
  - 计算当前梯度
  - 传递给next_functions
    ↓
在叶子节点累积梯度
```

**关键文件**:
- `torch/csrc/autograd/engine.h` - 引擎接口
- `torch/csrc/autograd/engine.cpp` - 执行逻辑

## 5. 算子定义格式

### 5.1 native_functions.yaml 结构

```yaml
- func: add.Tensor(Tensor self, Tensor other, *, Scalar alpha=1) -> Tensor
  device_check: NoCheck
  dispatch:
    CPU: add_cpu
    CUDA: add_cuda
  tags: pointwise
```

**字段说明**:
- `func`: 函数签名
- `dispatch`: 各后端的实现函数名
- `tags`: 用于优化的标签

### 5.2 从yaml到C++代码

TorchGen工具会从yaml生成:
1. C++函数声明
2. Python绑定代码
3. Dispatcher注册代码

生成的文件在: `build/aten/src/ATen/`
